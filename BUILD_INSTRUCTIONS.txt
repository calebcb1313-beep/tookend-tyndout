TOOKEND TYNDOUT: PRODUCE BRAWL — ANDROID PROJECT + APK BUILD

This project wraps the canvas fighting game (app/src/main/assets) in a
full-screen landscape Android WebView.

APK
---
A signed release APK ships next to this file:
  Tookend-Tyndout-Produce-Brawl-1.0.0.apk   (versionCode 8, versionName 1.0.0)
It is signed with keystore/tookend-release.jks, so newer builds install over
older ones. Sideloading only — not a Play Store bundle.

LOCAL BUILD (Android Studio)
----------------------------
1. Open this folder as an Android project.
2. Install Android SDK Platform 35 and Build-Tools 35.0.0 when prompted.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Output: app/build/outputs/apk/release/app-release.apk

COMMAND-LINE BUILD
------------------
  export JAVA_HOME=/path/to/jdk-17
  export ANDROID_HOME=/path/to/android-sdk
  ./gradlew assembleRelease

CLOUD BUILD (GitHub Actions)
----------------------------
Every push to main runs .github/workflows/android-apk.yml. It installs the SDK,
builds the signed release APK, verifies the signature and publishes the APK on
the v1.0.0 GitHub Release. Version names live in app/build.gradle; the release
tag and APK filename live in the workflow's RELEASE_TAG / APK_NAME env values.

WEB BUILD
---------
app/src/main/assets/index.html is a complete standalone build. Serve the folder
over HTTP(S) for the installable PWA (service worker + manifest), or open the
file directly — the game needs no network access.

GAME CONTENT
------------
Nine fighters, three arenas, one-player versus four CPU difficulties, local
two-player, a three-phase boss fight and training. Keyboard and multi-touch
controls, synthesized audio, adjustable graphics quality. See
app/src/main/assets/README.md for controls and systems.
