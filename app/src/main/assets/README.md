# TOOKEND TYNDOUT: The Rootbound Rebellion

A new, self-contained side-scrolling browser game prototype.

## Play
Open `index.html` in a modern browser. For Android installation/offline play, host this folder on HTTPS, open it in Chrome, then choose **Install app** / **Add to Home screen**.

## Controls
- Move: A/D or arrow keys
- Jump: W, Up, or Space
- Crouch: S or Down
- Fire: F or Enter
- Escape: pause
- Touchscreen: on-screen movement, jump, and fire controls

## Included
- Campaign with six themed regions and guardian boss fights
- Endless survival mode
- Procedurally drawn produce hero, enemies, bosses, platforms, projectiles, particles, and HUD
- Keyboard and touchscreen controls
- PWA manifest and service-worker offline cache

This is a playable prototype, not a finished commercial game. Progression is session-based; online multiplayer, saved progress, and sound are not included yet. A signed Android APK is published with each GitHub release.
